# Workplace Guard v0.1.0

Первый рабочий MVP системы обнаружения присутствия человека за рабочим компьютером.

## Что вошло

- YOLO11n обнаруживает только класс `person` в видеопотоке веб-камеры.
- Temporal confirmation требует несколько последовательных кадров и удерживает подтверждённый track при кратком пропуске.
- Pose validation проверяет сомнительные обнаружения с помощью YOLO11n-pose и keypoints головы, плеч и торса.
- В окне отображаются рамки подтверждённых людей, `People: N`, FPS и confidence.
- Debug mode (`--debug-detections`) показывает кандидатов, состояния `candidate/confirmed/lost` и причины отклонения.
- Camera diagnostics проверяет индексы и Windows backend DSHOW/MSMF с ограниченными таймаутами.
- HOG сохранён как резервный детектор (`--detector hog`).
- Подготовлены PyInstaller onedir-сборка и Inno Setup installer для Windows.

## Windows

Рекомендуемый артефакт релиза — `WorkplaceGuard-Setup-v0.1.0.exe`. Установщик размещает приложение в `Program Files`, создаёт пункт меню Пуск и позволяет добавить ярлык на рабочий стол. Python, OpenCV, Ultralytics/PyTorch и обе модели входят в установку.

## Ограничения MVP

Версия не определяет владельца рабочего места, не распознаёт личность и не отправляет уведомления. Качество фильтрации зависит от освещения, ракурса и сцены; параметры temporal и pose можно настроить через CLI или JSON-конфигурацию.
