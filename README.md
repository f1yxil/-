# Workplace Guard
Реализация проекта в области информационной безопасности с использованием технологии компьютерного зрения

Первый рабочий MVP системы обнаружения присутствия человека за рабочим компьютером.

YOLO11n обнаруживает людей в видеопотоке.

Temporal confirmation уменьшает одиночные ложные срабатывания.

Pose validation проверяет сомнительные обнаружения по keypoints.

Windows installer подготовлен через Inno Setup.

Debug mode показывает кандидатов, состояния и причины решений.

Camera diagnostics проверяет индексы камер и Windows backend DSHOW/MSMF.

HOG сохранён как резервный детектор.
