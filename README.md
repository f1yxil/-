# Система обнаружения присутствия постороннего человека

Учебный проект по компьютерному зрению и информационной безопасности. Цель
проекта — создать локальное приложение, которое наблюдает за рабочим местом
через веб-камеру и в дальнейшем сможет отличать владельца компьютера от
постороннего человека, вести журнал событий и отправлять уведомления.

> Текущий этап — **MVP захвата видео и обнаружения людей**. Программа не
> распознаёт личность и пока не должна использоваться как готовое средство
> защиты.

## Что уже работает

- получение кадров с веб-камеры через OpenCV;
- обнаружение людей встроенным HOG-детектором OpenCV без загрузки весов;
- рамки, оценка уверенности, FPS и количество найденных людей на экране;
- выбор камеры и настройка минимальной уверенности из командной строки;
- изолированные модули камеры и детектора, позволяющие позднее подключить YOLO;
- корректное освобождение камеры при завершении и базовые модульные тесты.

## Архитектура

```text
.
├── main.py                         # точка входа и цикл обработки видео
├── requirements.txt                # зависимости приложения и тестов
├── workplace_guard/
│   ├── __init__.py
│   ├── camera.py                   # чтение кадров и управление веб-камерой
│   └── detection.py                # интерфейс и HOG-реализация детектора
└── tests/
    ├── test_camera.py              # тесты модуля камеры с mock-объектом
    └── test_detection.py           # тесты фильтрации результатов детектора
```

`PersonDetector` — контракт для любого детектора людей. Сейчас его реализует
`HOGPersonDetector`; будущий `YoloPersonDetector` сможет реализовать тот же
метод `detect(frame)` и не потребует переписывать камеру или основной цикл.

## Требования

- Python 3.10 или новее;
- веб-камера, доступная операционной системе;
- графическая среда для окна OpenCV.

## Установка

```bash
git clone https://github.com/f1yxil/-.git
cd -

python -m venv .venv
```

Активация окружения:

```bash
# Linux/macOS
source .venv/bin/activate

# Windows PowerShell
.venv\Scripts\Activate.ps1
```

Установка зависимостей:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Для выхода нажмите `q` в окне с видео. Если основная камера имеет другой
номер, укажите его явно:

```bash
python main.py --camera-index 1
```

Дополнительные параметры:

```bash
python main.py --help
python main.py --confidence 0.6 --width 1280 --height 720
```

Если камера не открывается, закройте другие приложения, которые её используют,
проверьте разрешение на доступ к камере и попробуйте другой `--camera-index`.

## Тесты

Для тестов физическая веб-камера не требуется:

```bash
pytest
```
